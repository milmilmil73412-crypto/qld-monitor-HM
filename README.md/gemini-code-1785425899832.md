# QLD / TIGER 레버리지 자동 매수 알림 및 웹 대시보드 시스템

나스닥 100 2배 레버리지 ETF(QLD/TIGER 418660)의 지표를 모니터링하여, 매수 신호 및 현황을 **이메일 알림**으로 전송하고 **웹페이지 대시보드(GitHub Pages)**로 보여주는 시스템 명세서입니다.

## 1. 포트폴리오 및 자금 집행 전략

### 1.1 자산 배분 구조
* **투자 자산 (70%)**
  * `418660` **TIGER 미국나스닥100레버리지(합성)**: 60% (주력 레버리지 자산)
  * `486290` **TIGER 미국나스닥100타겟데일리커버드콜**: 30% (월 분배금 실탄 공급)
  * `DGRO` **iShares Core Dividend Growth ETF**: 10% (미국 직투 배당성장)
* **현금성 자산 (30%)**
  * `0046A0` **TIGER 미국초단기(3개월이하)국채**: 80% (매수 시 순차적 매도)
  * **CMA 통장**: 20% (즉시 매수용 현금 버퍼)

### 1.2 분할 매수 집행 규칙 (40 : 40 : 20 DCA)
1. **1차 매수 (1단계 신호 진입 시)**: 보유 현금(30%) 중 40%를 8주(2개월) 동안 매주 1/8씩 기계적 매수.
2. **2차 매수 (하락 지속 시)**: 8주 경과 후에도 신호 유지 시, 남은 현금의 40%를 2차 8주(총 16주) 동안 매수.
3. **3차 매수 (장기 하락장)**: 잔여 현금 20% 및 커버드콜/DGRO 배당금을 매월 신규 실탄으로 소진 시까지 매수.
4. **자금 인출 순서**: CMA 잔액 우선 사용 -> 부족 시 `0046A0(TIGER 미국초단기국채)` 매도하여 `418660` 매수.

## 2. 핵심 지표 및 상태 조건

* **200일선 괴리율 (일봉)**: (QLD 종가 - 200일선) / 200일선 * 100
* **주봉 RSI(14)**:
  * **화~금요일 아침**: 오늘 종가를 임시 포함한 **진행형 주봉 RSI** 사용
  * **토요일 아침**: 미국 금요일 마감 반영 **확정 주봉 RSI** 사용

### 상태 매트릭스
| 구분 | 상태 | 조건 (AND) | 설명 |
| :--- | :--- | :--- | :--- |
| **비신호** | 🟢 **안정** | 괴리율 > -5% **AND** 주봉 RSI > 55 | 평시 관망 구간 |
| **비신호** | 🟡 **관심** | 괴리율 -5% ~ -10% **OR** 주봉 RSI 48 ~ 55 | 매수 임계치 근접, 현금 사전 점검 |
| **신호** | 🟠 **1단계** | **주봉 RSI $\le$ 48 AND 괴리율 $\le$ -10%** | **분할 매수 시작** (8주 1차 구동) |
| **신호** | 🔴 **2단계** | **주봉 RSI $\le$ 42 AND 괴리율 $\le$ -18%** | **매력적 매수** (계획 철저 이행) |
| **신호** | 🟣 **3단계** | **주봉 RSI $\le$ 36 AND 괴리율 $\le$ -26%** | **역사적 바닥** (2차 8주 + 배당금) |

## 3. 출력 및 알림 사양

### 3.1 이메일 알림 (Gmail SMTP)
* 매일 아침 지정된 수신자 이메일로 HTML 형태의 깔끔한 알림 전송.
* 화~금요일은 `[진행형] QLD 데일리 모니터링`, 토요일은 `[확정] QLD 주말 확정 리포트` 제목으로 발송.

### 3.2 웹 대시보드 (GitHub Pages `index.html`)
* 매일 배치 작업 시 `index.html` 파일을 생성/업데이트하여 GitHub Pages를 통해 실시간 상태 웹페이지 제공.
* 웹페이지 구성 요소:
  * 현재 상태 카드 (🟢안정 / 🟡관심 / 🟠1단계 / 🔴2단계 / 🟣3단계)
  * QLD 종가, 200일선 괴리율, 주봉 RSI 수치 카드
  * 1단계 임계치까지 남은 수치(Margin) 진행바
  * 포트폴리오 가이드 및 매수 집행 규칙 지침

## 4. 시스템 구조 및 개발 요구사항

1. **`main.py`**: `yfinance` 기반 지표 계산, 상태 판정, 이메일 발송, `index.html` 파일 생성 기능 보유.
2. **`index.html`**: Bootstrap 또는 Tailwind CSS 기반의 반응형 모바일/PC 겸용 대시보드 템플릿.
3. **`.github/workflows/daily_run.yml`**:
   * 매일 아침 08:00 (KST) 자동 실행.
   * `main.py` 실행 후 변경된 `index.html`을 GitHub Pages 브랜치로 자동 배포/커밋.
